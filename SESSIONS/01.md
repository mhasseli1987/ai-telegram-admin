## Key Technical Details

### Security (Rule 13 Compliance)
- API keys & Telegram tokens: **AES-256-GCM encrypted**, never in logs/HTML/JS
- SSRF-Gate validates all outbound URLs (blocks private IPs, DNS rebinding)
- Nonce + Capability checks on all REST endpoints
- Prepared statements only (`$wpdb->prepare`)

### AI Layer
- Provider-agnostic via `AIProviderInterface`
- `OpenAICompatibleProvider`: baseUrl, apiKey, model, temperature, maxTokens, timeout, headers
- Operations: generate, rewrite, summarize, title, caption, translate

### Telegram Layer
- `TelegramProviderInterface`: getMe, getChat, sendMessage, sendPhoto, editMessageText, testConnection
- `BotApiTelegramProvider` adapter implementation

### Queue & Scheduler
- Atomic claim via SQL `UPDATE ... RETURNING`
- Exponential backoff retry (max 5 attempts)
- Cron cleanup of expired locks (5 min TTL)
- Separation: Scheduler = "when", Queue = "execution with retry"
